# 塵界のそうじクエスト

部屋の掃除を進めるための一人用RPG。ゴミを1個すてるたびに主人公が強くなる。

- **プレイ**: https://almadiehl.github.io/souji-quest/
- iPhone の Safari で開き、共有 →「ホーム画面に追加」でアプリのように使えます

## 中身

- 単一の HTML ファイル（外部ライブラリなし・オフライン動作）
- 記録は端末のブラウザ内にのみ保存されます。サーバーには何も送信しません
- 5エリア19体の魔物と、踏破後に開く無限の「深層」
- 掃除しないと強くなれない設計。ゴールドの使い道は装備と鍛錬のみ

## 開発メモ

- **[docs/SPEC.md](docs/SPEC.md) — 設計仕様書。** 引き継ぎと外部レビュー用。
  設計原則・数式・実行環境の制約・過去に踏んだ罠・変更時の手順がまとまっています。
- `node tools/sim.js` — 戦闘バランスのシミュレータ。**数値を触る前に必ず通すこと**
- `node docs/build-guide.js` — 装備カタログ（ネタバレあり）を実装から生成
